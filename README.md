# Covenant

An open-source Android launcher that turns your phone into a different phone at each time of day. You split the day into blocks, each with its own apps. Stricter changes apply instantly; any change that gives an app more time waits 72 hours.

Covenant has no internet permission, no analytics and no cloud backups. Everything stays on the phone.

**Status:** pre-alpha. Nothing to install yet.
