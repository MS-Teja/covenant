# Covenant

An open-source digital-detox launcher for Android. Your phone is calm by default: calls, payments, maps and messages always work, and feeds open only in the windows you planned, for the minutes you allowed. Stricter changes apply instantly; any change that gives an app more time waits 72 hours.

Covenant has no internet permission, no analytics and no cloud backups. Everything stays on the phone.

**Status:** pre-alpha. Nothing to install yet.
